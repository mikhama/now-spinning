# 3D Models

## Models used
The third-party models were not included in the Blender file due to licensing restrictions. If you need them as references or helpers while modifying my models, you can download them from the links below and import them separately.

- Used pi model [Raspberry Pi 4](https://www.printables.com/model/727545-raspberry-pi-4) by [Pyro_Industries](https://www.printables.com/@pyro).
- Used display model [4.3inch Waweshare Capacitive Display for Raspberry Pi, DSI, 800×480](https://grabcad.com/library/4-3inch-waweshare-capacitive-display-for-raspberry-pi-dsi-800x480-1) by [Oleksii Korzh](https://grabcad.com/oleksii.korzh-1).
- Used PN532 model [PN532 NFC RFID module V3 kits](https://grabcad.com/library/pn532-nfc-rfid-module-v3-kits-1) by [Alexey Voloshchenko](https://grabcad.com/alexey.voloshchenko-1).
